# Building-an-LLM-Powered-API-Interface

A project demonstrating how to build a **Large Language Model (LLM)** from scratch using **PyTorch**, and expose it through a **FastAPI interface** for real-time interaction. Inspired by Andrej Karpathy’s GPT-from-scratch tutorial, extended with API integration and deployment best practices.

---

## 🚀 Features
- **Custom PyTorch Language Model**  
  Implemented character-level tokenization, embeddings, and transformer blocks for text generation.
- **FastAPI Integration**  
  Designed RESTful endpoints to query the LLM and return contextual responses in real time.
- **Performance Optimization**  
  Leveraged CUDA acceleration and ONNX export to reduce inference latency and improve scalability.
- **Documentation & Usability**  
  Clear setup instructions, architecture overview, and sample API calls for easy onboarding.

---

## 🛠️ Tech Stack
- **Languages**: Python  
- **Frameworks**: PyTorch, FastAPI  
- **Tools**: Docker, ONNX, CUDA  
- **Cloud**: Azure Cognitive Services, Azure Blob Storage (optional for scaling)
